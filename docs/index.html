Iriscan developer documentation

Iriscan builds biometric components that you can run on your own infrastructure: face, liveness and iris recognition for mobile and server, fingerprint template conversion between ISO and ANSI formats, and a REST service for iris enrolment and matching. The core libraries are open source.

Biometric SDK

Face detection, FaceNet templates, liveness and iris recognition on Android, iOS, JVM and React Native. Runs on the device, no server required.

Open source · Kotlin Multiplatform

Biometric Converter

Fingerprint images (WSQ, PNG, JPEG, JPEG 2000) to minutiae templates and templates between ISO/IEC 19794-2 and ANSI INCITS 378.

Open source · C · REST · WebAssembly

Cloud Iris API

Enrol people with left and right eye images, identify them 1:N or verify 1:1 over REST. Each tenant gets an isolated database.

REST · API key

Edge service

A local service for Iritech iris scanners and webcams: capture, quality score, live preview and an encrypted local person store that syncs with the cloud.

Windows · Linux

MOSIP and Inji

The face match SDK used by Inji Wallet, the reference wallet of the MOSIP national ID platform, for offline selfie verification.
