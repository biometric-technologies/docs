Cloud Iris API

Iris recognition as a REST service. Enrol a person with left and right eye images, then find them among everyone enrolled (1:N) or confirm a claimed identity (1:1). Each customer is a tenant with its own isolated database.

Base URL:

https://api.iriscan.net

Authentication

Every request carries the tenant's API key in the Api-Key header.

curl https://api.iriscan.net/persons/query?page=0&pageSize=20 \
  -H "Api-Key: $IRISCAN_API_KEY"

API keys are issued per tenant together with the monthly plan. To get one, contact us with the expected number of enrolments and identifications per month; on-premise deployment with the Edge service is arranged the same way.

How matching works

When a person is enrolled, each eye image is segmented, the iris ring is unwrapped and encoded into a binary iris code with a mask of unusable bits (eyelids, lashes, reflections). The response returns both, plus blackPercentage, the share of the iris hidden by occlusion. A high value means too little texture was visible, and the image is worth retaking.

find compares a probe eye against every enrolled template of the tenant and returns the best match, or 404 when nobody matches. verify compares the probe only against the given person and returns 412 when it does not match. Images are sent as base64 strings; near-infrared images from dedicated iris scanners give the best results.

Errors

Status Meaning
400 Malformed request or image
401 Missing or invalid Api-Key
404 Person not found, or no match for find
412 verify: the eye does not match the person
422 Validation failed; errors lists the fields

Error bodies have the same shape:

{
  "timestamp": "2021-03-02T10:15:30Z",
  "status": "UNPROCESSABLE_ENTITY",
  "message": "Validation failed",
  "errors": ["name: must not be blank"]
}

Reference

POST/persons

Add a new person to the database

Request body

FieldTypeDescription
namestringDisplay name of the person
leftEyestring (base64 image)Left eye image, base64 (PNG or JPEG)
rightEyestring (base64 image)Right eye image, base64 (PNG or JPEG)
metadataobjectAny JSON object stored with the person, returned as is

Example

curl -X POST "https://api.iriscan.net/persons" \
  -H "Api-Key: $IRISCAN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Jane Doe",
  "leftEye": "<base64 image>",
  "rightEye": "<base64 image>",
  "metadata": {
    "employeeId": "E-1042"
  }
}'

Response 200

{
  "id": "6041f3a2c1e8",
  "tenantId": "5f9b1c7e2a44",
  "iris": {
    "leftEye": {
      "raw": "<base64>",
      "code": "<base64 iris code>",
      "mask": "<base64 mask>",
      "blackPercentage": 0.12
    },
    "rightEye": {
      "raw": "<base64>",
      "code": "<base64 iris code>",
      "mask": "<base64 mask>",
      "blackPercentage": 0.09
    }
  },
  "metadata": {
    "employeeId": "E-1042"
  }
}

Responses

200Success401Unauthorized422Validation failed
